# RojinaSaberi_COMP254Lab7

A COMP254 binary search tree lab with a Streamlit tutor app that shows insertion, search, and ordered traversal.

## What This Project Is About

This repository contains Java tree exercises centered on binary search tree behavior. It now also includes a Streamlit tutor app that lets users build a BST interactively and learn how node placement affects search speed and sorted traversal output.

This is a **Java binary search tree project with an AI tutor style Streamlit app**.

## What The Tutor App Teaches

- how BST insertion follows left-smaller and right-larger rules
- why inorder traversal returns sorted values
- how search becomes efficient in a well-structured tree
- how tree shape affects performance

## Project Structure

- `app.py` - Streamlit tutor app
- `requirements.txt` - Python dependencies for the tutor app
- `src/com/exercise1/rojina/saberi/`
- `src/com/exercise2/rojina/saberi/`

## Run The Streamlit App

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Open The Java Project

Import into Eclipse and run `Exercise1Main` and `Exercise2Main`.
