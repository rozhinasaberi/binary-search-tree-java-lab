# RojinaSaberi_COMP254Lab7

A COMP254 Java lab centered on binary search tree operations and tree-based exercises.

## What This Project Is About

This lab implements a binary search tree and includes main classes for demonstrating insertion, inorder traversal, and iterative search behavior. It serves as a follow-up tree-focused project in the COMP254 course sequence.

This is a **Java binary search tree lab**.

## Exercises Included

- `exercise1` - binary search tree implementation and demo
- `exercise2` - additional tree-related lab exercise

## Project Structure

- `src/com/exercise1/rojina/saberi/`
- `src/com/exercise2/rojina/saberi/`

## Open Or Run

Import into Eclipse and run:

- `Exercise1Main`
- `Exercise2Main`
